# Project Statement


## Problem Statement

Restaurant waiting times can vary depending on the day and time, making it difficult for customers to plan their visits. This project uses machine learning to predict the expected restaurant waiting time based on the **day of the week and hour of the day**.

## Scope

The project focuses on generating a synthetic restaurant waiting-time dataset, preprocessing the data, training a machine learning model, evaluating its performance, and predicting waiting time for user-provided inputs.

The project is developed for **academic purposes** and does not use real-time restaurant data.

## Target Users

* Students
* Restaurant customers
* Users who want to estimate waiting time before visiting a restaurant

## High-Level Features

* Synthetic restaurant waiting-time dataset generation
* Data preprocessing
* Decision Tree Regression model
* Waiting-time prediction
* Model evaluation using MAE
* User input validation
* CSV dataset generation

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* GitHub
